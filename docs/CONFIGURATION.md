# 配置参考

日常使用建议通过 **设置 → 鱼的生活** 修改。手动编辑适合迁移、备份和批量调整；保存前请保留副本。

## 文件位置

所有路径都以 `DSH_HOME` 为根目录；未设置该环境变量时使用 `~/.dsh`。

| 内容 | 默认路径 |
|---|---|
| 生活配置 | `feiyu-life-config.json` |
| 每日剧本 | `feiyu-life-days/<YYYY-MM-DD>.json` |
| 重生成历史 | `feiyu-life-days/history/<YYYY-MM-DD>/` |
| 临时调整 | `feiyu-life-facts/<YYYY-MM-DD>.json` |
| 相机配置 | `feiyu-life-image-config.json` |
| 照片和角色参考图 | `feiyu-life-image/` |
| 生活/相机日志 | `feiyu-life*.log` |

旧版 `feiyu-image-config.json` 和 `feiyu-image/` 仍可读取，并会迁移到当前命名空间。

## 生活配置

当前生活配置版本为 `7`。读取旧配置时会自动补齐新字段并保留兼容数据；旧版 `事件池` 会被移除，生活细节统一由每日模型剧本生成。

| 字段 | 类型 | 默认值/范围 | 说明 |
|---|---|---|---|
| `配置版本` | number | `7` | 由插件维护，不建议手动修改 |
| `总开关` | boolean | `true` | 关闭后不向角色会话注入生活状态 |
| `时区` | string | `Asia/Shanghai` | 必须是有效 IANA 时区 |
| `工作区` | string[] | `[]` | 目录前缀白名单；空数组代表所有顶层会话 |
| `模型超时秒` | number | `60`，范围 10–300 | 每日剧本模型调用的硬截止时间 |
| `历史保留天数` | number | `180`，范围 7–3650 | 剧本、重生成快照和调整记录的保留期 |
| `地图` | object | 见下文 | 地点、路径、坐标和自动通勤 |
| `经期` | object | 起始日、周期、天数 | 用于当天身体底色，不作医疗判断 |
| `校历` | object | 学期/假期/特殊 | 决定是否上课以及使用哪张作息表 |
| `节日` | object[] | 公历日期 | 支持每年固定日或明确的起止日期 |
| `日常/晚起/假期/备考` | array[] | 四张作息表 | 每行是起、止、内容、手机状态 |
| `晚起日` | number[] | `[4]` | ISO 星期，1=周一、7=周日 |
| `课表` | object | `1`–`7` | 每个星期下的课程时段 |
| `偏离` | object | 0–1 概率 | `躺平日`、`出门日`、`翘下午课` |

### 作息和课表行

```json
["08:00", "11:30", "教学楼上课", "静音"]
```

四项依次为：开始时间、结束时间、活动短句、手机状态。手机状态只能是：

- `在手`
- `静音`
- `在床头`
- `不在手边`

时间使用 24 小时制；`24:00` 只应作为结束边界。作息表需要覆盖整天，并至少包含六小时睡眠，否则模型剧本会被判定不合格并退回模板。

### 校历和节日

```json
{
  "校历": {
    "学期": [{ "名": "秋季学期", "起": "2026-09-07", "止": "2027-01-17" }],
    "假期": [{ "名": "寒假", "起": "2027-01-18", "止": "2027-02-21", "作息": "假期" }],
    "特殊": [{ "名": "期末周", "起": "2027-01-04", "止": "2027-01-17", "作息": "备考" }]
  },
  "节日": [
    { "名": "元旦", "月": 1, "日": 1 },
    { "名": "国庆", "起": "2026-10-01", "止": "2026-10-07" }
  ]
}
```

优先级为：特殊时段 > 假期 > 放假节日 > 学期。农历节日不会自动换算，应填写对应年份的公历起止日期。

## 地图配置

```json
{
  "地图": {
    "启用": true,
    "自动通勤": true,
    "地点": [
      {
        "id": "dorm",
        "name": "学生公寓",
        "icon": "bed",
        "x": 44.3,
        "y": 51.3,
        "关键词": ["宿舍", "床", "睡", "洗漱"]
      }
    ],
    "路径": [
      { "from": "dorm", "to": "canteen", "minutes": 8 }
    ]
  }
}
```

### 地点

| 字段 | 规则 |
|---|---|
| `id` | 唯一；只允许字母、数字、下划线和连字符，最多 40 字符 |
| `name` | 展示名称，最多 40 字符 |
| `icon` | 设置页内置的地点图标 ID；未知值会安全回退为地图图钉 |
| `x` | 地图横坐标，保存时限制到 4–96 |
| `y` | 地图纵坐标，保存时限制到 8–92 |
| `关键词` | 从活动短句推断地点；每项最多 24 字符、每地最多 30 项 |

至少需要两个有效地点，否则会恢复默认地图。多个关键词同时命中时，优先采用更长、更具体的词；没有任何命中时优先回到 `dorm`，否则使用第一个地点。对咖啡店、咖啡馆、书店、餐厅、电影院等明确的校外目的地保留语义兜底，已有配置尚未补充新关键词时也不会错误回到宿舍。

### 路径

`from` 和 `to` 必须引用现有地点，且不能相同。`minutes` 保存时限制到 1–180。路径按双向边处理，跨地点时使用最短耗时路线；若两地不可达，会使用 12 分钟直连兜底。默认路径由地图生成脚本在 OSM 最大连通步行图上计算，不再手工维护折点。

关闭 `地图.自动通勤` 后仍会推断并显示当前地点，但不会向时间线插入移动段。关闭 `地图.启用` 后不再展示空间状态。

默认 `地图.底图` 为 `xueyuan-road`，显示中国矿业大学（北京）学院路校区及周边的离线分层地图；设为 `none` 时回退到抽象校园景观。默认九地点包含校内建筑、咖啡屋·上岛咖啡、BOM 嘻番里和麦当劳·成府路。路径可带 `via: [{x, y}]` 折点，地图道路和角色移动使用同一组折点。配置版本 5 开始只替换完全未改动的 v3/v4 默认地图，手动调整过的地点不会被覆盖；版本 6 移除了重复的 `事件池`；版本 7 为地点补充可配置的本地图标。

## 行为识别

新生成的每日剧本会显式保存 `locationId` 和 `behavior`；`life_adjust` 也可选填这两个字段。显式字段经过枚举校验后优先使用，旧剧本或缺失字段才按活动短句依次匹配。设置页「地图 → 识别测试」与运行时使用相同规则。

兜底映射如下：

| 行为 | 关键词示例 |
|---|---|
| `sleep` | 睡、午睡、眯 |
| `walk` | 走、路上、出发、去往、地铁、公交 |
| `eat` | 吃饭、食堂、早餐、午饭、晚饭、吃外卖、喝奶茶；排除等/点/取外卖和旁观、喂宠物语境 |
| `study` | 上课、自习、背书、复习、看书、作业、写稿、改稿、写作、码字、论文、海报、剪片、修图 |
| `photo` | 拍照、相机、自拍 |
| `bath` | 洗澡、洗漱、刷牙、洗脸；使用独立四帧透明动作条 |
| `phone` | 刷手机、回消息、打游戏、B站、看剧、刷视频等明确短语 |
| `idle` | 未命中上述规则 |

自动通勤段固定为 `walk`。行为规则当前属于代码逻辑，不在设置页中编辑；可在设置页直接测试短句。地点推断未命中关键词时，时间线承接段会沿用上一段地点；独立调用地点推断时仍以宿舍或第一个地点兜底。

## 相机配置

相机配置与生活配置分开存放，当前版本为 `3`。

| 字段 | 默认值/范围 | 说明 |
|---|---|---|
| `总开关` | `true` | 控制 `shoot` 工具 |
| `模型` | Seedream Pro | 主生图模型 |
| `备用模型` | Seedream Flash | 主模型失败后的备用 |
| `用参考图` | `true` | 自拍是否附带角色参考图 |
| `参考图` | 空 | 文件、目录或换行/逗号分隔的多路径；留空自动扫描默认角色设定目录，最多 10 张 |
| `外观/服装/风格/镜头/表情/细节` | 文本 | 组成自拍基础提示词 |
| `画幅` | `竖幅` | 可选 `竖幅`、`方形`、`横幅` |
| `清晰度` | `2K` | 可选 `2K`（细节优先）或 `1.5K`（速度优先） |
| `提示词加工` | `模型` | 模型扩写或本地模板 |
| `出图自检` | `true` | 检查角色、画风、肢体和文字水印 |
| `自检重拍` | `1`，范围 0–2 | 自检不通过时最多重拍次数 |
| `每日上限` | `8`，范围 1–100 | 对话拍照和设置页试拍共用 |
| `最短间隔秒` | `30`，范围 0–86400 | 两次成功请求的最短间隔 |
| `模型超时秒` | `60`，范围 10–300 | 提示词扩写和视觉检查 |
| `生图超时秒` | `120`，范围 30–600 | 生图和下载截止时间 |
| `照片保留天数` | `90`，范围 1–3650 | 只清理插件生成的照片 |
| `存图目录` | 空 | 留空使用 `feiyu-life-image/` |
| `兜底Provider/兜底模型` | DeepSeek 默认值 | 提示词加工的模型兜底 |

默认参考图目录为 `feiyu-life-image/角色设定/`，同时兼容旧目录；目录没有图片时使用 npm 包内置的 `assets/character-sheet.png` 三视图。目录内 PNG、JPEG、WebP 会按正面、三视图/设定图、侧面、背面、其他的顺序选取；配置字段也支持 `~`、单文件、目录以及多行路径。Seedream 5.x 默认请求 PNG、标准提示词优化模式和对应画幅的 2K 尺寸；聊天分享副本最长边为 2048px、JPEG q93、4:4:4 采样，完整原图仍单独保留。照片历史按需生成 `feiyu-*-thumb.jpg` 缓存，首屏只请求少量缩略图，打开大图时才读取原文件。

每张新照片会同时生成同时间戳的 `feiyu-<timestamp>.json`，记录拍摄时的生活地点、活动、时间、穿着、表情、光线、生图模型、画幅、提示词和自检结果。相册只读取这些旁车元数据解释照片，不反向修改生活状态。清理任务会同时处理原图、分享图、缩略图和元数据，不会触碰角色设定目录。

## 保存、迁移与清理

- 设置页保存时会规范化所有用户字段，并将修正项返回界面；
- 配置采用临时文件后原子替换，降低半写入风险；
- 新版本读取旧配置时自动迁移并写回当前版本；
- 插件启动后会执行维护任务，此后约每 24 小时清理过期数据；
- 日志达到 1 MiB 后轮转，保留三份历史；
- 手动修改无效字段时，插件可能忽略该项或恢复默认值。

实现边界和模块职责见 [整体设计](./DESIGN.md)。
