# 设置页字段映射

顶层页面：此刻 / 生活 / 内在 / 主动 / 世界 / 相机 / 数据。页面只改变信息架构，配置 key、默认值和保存路径不变。

| 顶层 | 分区 | 配置/状态 | 说明 |
|---|---|---|---|
| 此刻 | — | 只读 state/preview/meta | 当前活动、地点、衣着、焦点、内部证据、调整历史；无编辑表单 |
| 生活 | 作息 | `日常` `晚起` `假期` `备考` `晚起日` | 作息表 |
| 生活 | 课表 | `课表` | 周课表 |
| 生活 | 年度 | `校历` `节日` `经期` `偏离` | 年度/假期/考试周/身体偏差 |
| 生活 | 身体 | 只读 vitality/reply/moment | 身体与当前状态 |
| 生活 | 角色与衣柜 | `角色设定` `衣柜` | 作息页顶部角色设定和六类衣柜 |
| 内在 | 人格 | `人格.*`（自我叙事/特质/价值/记忆策略/外部兼容） | 只读认知 + 可编辑策略 |
| 内在 | 内在 | `内在.*`（启用/反思/基线/阈值/Provider/模型） | 情绪与反思 |
| 内在 | 连续性 | `连续性.*` | 事项、人物、记忆、结算 |
| 主动 | 分享 | `主动分享.*` | 开关、额度、冷却、安静、近期对话、最低分；不暴露内部状态机 |
| 世界 | 地图 | `地图.*` | 地点、路径、行为预览 |
| 世界 | 回放 | 只读 replay | 当日地图/行为回放 |
| 相机 | 照片 | image config / photos | 模型、参考图、质量、图库、清理 |
| 数据 | — | `工作区` `模型超时秒` `历史保留天数` `时区` | 备份/恢复、诊断、版本 |

配置字段归组测试见 `test/ui-page-map.test.js`。危险操作（恢复、清理）仍保留确认/错误状态。
