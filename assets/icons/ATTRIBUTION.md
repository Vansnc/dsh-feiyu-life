# Icon attribution

界面行为图标与地图通用地点图标通过 Iconify MCP 获取，并以 SVG path 快照形式内嵌在 `client.js`，运行时不访问 Iconify API 或 CDN。

- [Lucide](https://lucide.dev/)：`sparkles`、`moon`、`footprints`、`pencil`、`utensils`、`smartphone`、`camera`、`bath`、`bed`、`school`、`library-big`、`soup`、`store`、`trees`、`coffee`、`shopping-bag`，ISC License。
- [Simple Icons](https://simpleicons.org/)：`mcdonalds`，CC0 1.0。

项目自己的鲸鱼时钟品牌图标不属于上述图标集。
